## 1. Contribution & Motivation  
### Problem Statement   
- 기존 SSL 방법들 
    1. Pretext tasks (초기 방법)
        - 손으로 설계한 가짜 과제, representation 학습 (ex. rotation prediction, jigsaw puzzle, colorization)
        - 문제: 과제에만 특화된 feature 학습 → 일반화 부족 

    2. Contrastive methods (SimCLR, MoCo 등)
        - 같은 이미지는 비슷한 위치에, 다른 이미지는 먼 위치에 두도록 학습 => **같은 이미지에서 나온 두 augmentation view \(x_1, x_2\)를 가깝게** 만듦. (x1과 x2의 공통점은 무엇인가?)
        - 문제: negative sample이 대량으로 필요함 (→ 큰 배치 크기, 복잡한 메모리 뱅크 필요), augmentation 선택에 민감  
            - augmentation 선택에 민감한 이유?  
                - x1, x2 = 같은 이미지의 두 augmentation 
                - augmentation이 너무 약하면 → 두 view가 거의 비슷하기 때문에 저수준 특징(밝기, 색감, 텍스처 등)만으로도 쉽게 문제를 풀 수 있음. (=> shortcut learning)
                - augmentation이 너무 강하면 → 두 view가 거의 겹치지 않아 같은 이미지에서 나왔더라도 실질적으로 다른 이미지가 됨 (pair가 깨지고 학습이 불안정)

### Key contribution   
- **negative sample 없이도** self-supervised learning을 할 수 있다. 

### Critical View
- 단순한 \(L_2\) 손실 함수 + 비대칭적 구조(Predictor 추가)만으로 collapse 방지

## 2. Architecture & Pipeline  
![BYOL overview](/assets/img/BYOL_architecture.png)  
- 온라인 네트워크(Online Network)와 타겟 네트워크(Target Network)가 상호작용 
- **Input/Output:** 하나의 이미지 \(x\)에서 두 가지 증강된 뷰 \(v, v'\)가 생성
    - 온라인 네트워크는 \(v\)를 입력받아 예측값 \(q_\theta(z_\theta)\)를 출력하고, 타겟 네트워크는 \(v'\)를 통해 타겟 \(z'_\xi\)를 생성.
- **Module:** 
    - **Encoder (\(f_\theta, f_\xi\)):** 주로 \(ResNet\) 구조를 사용
    - **Projector (\(g_\theta, g_\xi\)):** 표현(Representation)을 투영 공간으로 보냄
    - **Predictor (\(q_\theta\)):** 온라인 네트워크에만 존재하며, 타겟의 표현을 예측


## 3. Methodology & Theory 
- 각 네트워크 구성   
    | 구성요소 | Online | Target |
    |---|---|---|
    | Encoder \(f\) | ResNet-50 | ResNet-50 동일 |
    | Projector \(g\) | 2-layer MLP | 2-layer MLP 동일 |
    | Predictor \(q\) | 있음 | 없음 |
    | 업데이트 | gradient descent | EMA only |

- Loss Function 
    - L2 정규화 후 온라인 네트워크의 예측값 \(\bar{q}_\theta(z_\theta)\)과 타겟 네트워크의 투영값 \(\bar{z}'_\xi\) 비교  
        $$
        L_{\theta,\xi} = \left\| \bar{q}_\theta(z_\theta) - \bar{z}'_\xi \right\|_2^2 = 2 - 2 \cdot \frac{\langle q_\theta(z_\theta), z'_\xi \rangle}{\| q_\theta(z_\theta) \|_2 \cdot \| z'_\xi \|_2}
        $$ 
    - 정규화하는 이유: 벡터 방향(각도)만 비교. 크기는 무시.   
    - **Symmetric Loss**
        ```text  
        방향 1: v  → online, v' → target  → Loss₁  
        방향 2: v' → online, v  → target  → Loss₂  

        총 Loss = Loss₁ + Loss₂

- EMA 업데이트
    - 타겟 네트워크의 파라미터 \(\xi\)는 온라인 네트워크 파라미터 \(\theta\)의 지수 이동 평균(EMA)으로 업데이트  
        $$
        \xi \leftarrow \tau \xi + (1 - \tau)\theta
        $$
    - \tau 가 점점 커질수록 target이 더 천천히 변함 → 학습 후반 안정성 증가 

- collapse ? 
    - collapse : 모든 이미지가 같은 벡터로 매핑되는 것 
    - 왜 일어나는가?  online(x₁) ≈ target(x₂)의 목표를 이루기 위한 가장 쉬운 방법은 둘 다 [0, 0, .., 0]을 출력하는 것 → loss = 0, but 아무것도 학습하지 않음
    - EMA로 target을 업데이트 하는 것도 결국 online이랑 겹쳐지지 않는가?
        - 이론적으로는 맞음. (결국 수렴함)
        - 이를 해결하기 위한 설계 방법  
            1. predictor 비대칭: online만 predictor가 있음 → 구조적으로 달라서 완전 동일 불가  
            2. stop-gradient: target은 gradient를 받지 않음, EMA로만 업데이트 → 일방향 관계, 속도 차이 유지  
            3. BatchNorm: 상수로 수렴하는 것을 구조적으로 방지  
    



## 4. 실험 및 데이터 (Experiments & Results)  
- **Datasets:** \(ImageNet\) (ILSVRC-2012)에서 주로 학습 및 평가되었으며, \(VOC\), \(COCO\), \(NYU\) \(v2\) 등으로 전이 학습 성능을 측정
- **Baselines:** \(SimCLR\), \(MoCo\) \(v2\), \(CPC\) \(v2\) 등 주요 대조 학습 모델들과 비교되.
- **Performance:** \(ResNet-50\) 기반 선형 평가에서 \(74.3\%\)의 \(Top-1\) 정확도를 기록.
- **Ablation Study:** 배치 크기가 \(4096\)에서 \(256\)으로 줄어들어도 \(SimCLR\)에 비해 성능 하락이 매우 적음을 보임. 또한 컬러 왜곡(Color Jittering)을 제거했을 때 \(SimCLR\)은 성능이 급락(\(-22.2\%\))한 반면 \(BYOL\)은 상대적으로 선방(\(-9.1\%\))
