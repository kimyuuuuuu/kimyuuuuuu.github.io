# FiLM: Visual Reasoning with a General Conditioning Layer

[FiLM paper (2018)] 리뷰  

## 기본 정보 
- 논문 제목: FiLM: Visual Reasoning with a General Conditioning Layer
- 저자: Ethan Perez, Florian Strub, Harm de Vries, Vincent Dumoulin, Aaron Courville
- 소속: MILA, Université de Montréal, Rice University, Université de Lille 등. 
- 학회/연도: AAAI, 2018. 
- 핵심 키워드: FiLM, Feature-wise Linear Modulation, Visual Question Answering, visual reasoning, conditional computation
- 코드: github.com/ethanjperez/film.

## 1. Contribution & Motivation
- Agent(인공지능 시스템, 모델)가 복잡하고 구조화된 과정을 학습하려면 Reasoning을 내재화해야 했음
    - Reasoning e.g., compositionality, relational computation
    - 기존 모델들은 추론을 위해 명시적인 구조(Module)를 넣어야 한다고 주장했음
        - Neural Module Network, PG+EE: 질문을 프로그램으로 바꿔 모듈을 조립했음 → 강한 구조적 prior와 program label이라는 추가 supervision이 필요했음
        - Relation Network: 위치 쌍을 모두 비교하는 관계 prior를 썼음 → 연산량이 공간 해상도의 제곱에 비례했음
    - FiLM은 명시적인 구조를 쓰지 않고 범용 부품(CNN + GRU)과 conditioning만으로 추론이 가능함을 보였음
- Contribution
    1. CLEVR 등 visual reasoning task에서 SOTA를 달성했음 (추가 supervision이 없는 방법 기준 error를 4.5%에서 2.3%로 줄였음)
    2. FiLM이 feature를 선택적이고 일관되게 변조함을 분석으로 보였음 (질문과 관련된 객체를 localize했음)
    3. ablation에 강건했음. conditioned affine 변환의 효과가 normalization과 밀접하게 연결되어 있지 않음을 보였음
    4. 적은 데이터로 새로운 분포에 일반화했음. FiLM 기반 zero-shot 일반화 방법도 제안했음

- **질문 경로 (FiLM generator)**
    - 학습되는 200차원 word embedding을 GRU에 넣고, 마지막 4096차원 hidden state를 질문 표현으로 사용했음
    - 이 질문 표현에서 각 residual block에 필요한 $$(\gamma, \beta)$$를 affine projection으로 예측했음
- **영상 경로 (FiLM-ed network)**
    - 이미지를 $$224\times224$$로 resize했음
    - CNN이 128개의 $$14\times14$$ feature map을 출력했음
        - scratch로 학습하는 CNN (4 layer, 128개 $$4\times4$$ kernel, ReLU, BN) 또는
        - ImageNet으로 사전학습한 ResNet-101의 conv4 출력(고정) + 학습되는 $$3\times3$$ conv
    - 128 feature map을 갖는 FiLM residual block 4개를 거쳤음
- **Residual block 구조**
    - $$1\times1$$ conv → ReLU → $$3\times3$$ conv → BN → FiLM → ReLU → residual 연결
    - FiLM 바로 앞 BN의 affine 파라미터는 꺼 두었음 (FiLM이 그 역할을 대신했음)
- **공간 정보**
    - 상대적인 $$x, y$$ 위치(−1 ~ 1)를 나타내는 좌표 feature map 2개를 영상 특징, 각 ResBlock 입력, classifier 입력에 concat해서 공간 추론을 도왔음
- **Classifier**
    - $$1\times1$$ conv(512) → global max-pooling → hidden 1024인 2-layer MLP → 28개 답 후보에 대한 softmax 분포를 출력했음

## 3. Methodology & Theory 
### FiLM: Feature-wise Linear Modulation
- 어떤 input(조건)을 기반으로 신경망의 중간 feature에 affine 변환을 적용해서 output을 조절했음
- Conditional Normalization(CN)을 일반화한 것이었음
    - 단, 논문은 normalization이 필수가 아님을 보였음 → 이름에서 normalization을 빼고 "feature-wise affine 변환"으로 정의했음

### 일반 Batch Norm

$$
y = \gamma\hat{x} + \beta
$$

- 입력 feature를 정규화한 뒤, 학습 가능한 scale·shift 파라미터를 적용했음
- $$\hat{x}$$는 정규화된 입력이고, $$\gamma, \beta$$는 학습되는 파라미터였음
- 학습이 끝나면 층의 채널마다 값이 고정되므로, 입력 샘플이나 조건에 따라 달라지지 않았음

### Conditional Normalization
- $$\gamma, \beta$$를 고정된 학습 파라미터로만 두지 않았음
- 별도의 조건 입력 $$c$$(e.g., 질문)를 받아 $$\gamma, \beta$$를 계산하는 generator가 있었음

$$
\gamma = g_\gamma(c), \qquad \beta = g_\beta(c)
$$

$$
y = \gamma(c)\hat{x} + \beta(c)
$$

- 조건이 달라지면 $$\gamma, \beta$$도 달라지므로, 같은 시각 네트워크라도 feature를 처리하는 방식이 달라졌음
- 즉, 같은 네트워크라도 조건이 바뀌면 동작이 달라졌음

### FiLM 수식

$$
\gamma_{i,c} = f_c(x_i), \qquad \beta_{i,c} = h_c(x_i)
$$

$$
\text{FiLM}(F_{i,c} \mid \gamma_{i,c}, \beta_{i,c}) = \gamma_{i,c}F_{i,c} + \beta_{i,c}
$$

- $$F_{i,c}$$: $$i$$번째 입력의 $$c$$번째 feature map
- $$f, h$$는 파라미터를 공유하는 하나의 네트워크로 묶어 FiLM generator라 불렀음
- 변조는 영상 위치마다 따로 생성되지 않고 feature map 단위로 이뤄졌음 → feature map의 활성 분포를 조절하는 방식이었음
- feature map당 파라미터가 2개뿐이라 효율적이었고, 연산 비용이 이미지 해상도와 무관했음
- ReLU와 결합하면 feature map을 키우거나($$\gamma \gg 1$$), 끄거나($$\gamma \approx 0$$), 부호를 뒤집거나($$\gamma < 0$$), thresholding($$\beta < 0$$)할 수 있었음

### Loss Function
- classifier가 28개 답 후보에 대한 softmax 분포를 출력했음 (논문에 loss가 명시되지는 않았지만 softmax 분류이므로 cross-entropy로 보는 것이 자연스러웠음)
- image-question-answer triplet만으로 end-to-end 학습했음 (data augmentation, program label 사용 X)
- Adam (lr 3e-4), weight decay 1e-5, batch 64, validation accuracy 기준 early stopping (최대 80 epoch)을 사용했음

### Algorithm: 학습 및 추론 흐름
1. 질문을 word embedding과 GRU로 인코딩해 질문 표현을 얻었음
2. 질문 표현을 각 FiLM residual block에 대응하는 $$(\gamma, \beta)$$로 변환했음
3. 이미지를 CNN 또는 사전학습 feature extractor로 처리했음
4. residual block에서 FiLM 변환을 적용해 질문에 조건화된 시각 feature를 계산했음
5. classifier가 최종 feature로 답 분포를 출력했음

## 4. 실험 및 데이터 (Experiments & Results)  
### Datasets
- **CLEVR**: 다단계·조합적 질문이 들어 있는 합성 시각 추론 데이터셋이었음. 700K개의 (image, question, answer, program) tuple로 구성되었음
- **CLEVR-Humans**: 사람이 작성한 더 다양한 표현과 복잡한 질문으로 현실적 질문에 대한 일반화를 시험했음. train 18K, val 7K, test 7K 규모였음
- **CLEVR-CoGenT**: 학습과 평가 조건에서 물체의 색상·형태 조합을 바꿔 조합적 일반화와 학습된 bias를 조사했음

### Results
- CLEVR: 97.7%로 인간(92.6%)과 기존 방법들을 넘었음. raw pixel 입력으로도 97.6%로 비슷했음
- CLEVR-Humans: linguistic pipeline(GRU 쪽)만 fine-tuning해서 75.9%를 기록했고, PG+EE보다 9.3%p 높았음
- CoGenT: 조합 일반화에서 PG+EE보다 나았음. 다만 fine-tuning 뒤 catastrophic forgetting은 여전히 발생했음
- Zero-shot: $$(\gamma, \beta)$$ 공간에서 선형 조합으로 처음 보는 조합을 처리했음 (e.g., cyan cube = cyan sphere + brown cube − brown sphere). 적용 가능한 질문에서 71.5% → 80.7%로 올랐음

### Ablation & Analysis
- $$\gamma$$가 $$\beta$$보다 중요했음: test 때 β를 평균값으로 바꾸면 −1.0%, γ를 평균값으로 바꾸면 −65.4%
- γ 범위를 sigmoid(0, 1), tanh(−1, 1), exp(0, ∞)로 제한하면 성능이 떨어졌음 → 0, 음수, 큰 값을 모두 낼 수 있어야 했음
- FiLM 위치를 ResBlock 안에서 옮겨도 성능이 크게 떨어지지 않았음 → normalization 바로 뒤에 둘 필요가 없었음
- FiLM을 한 층에만 넣어도 97.3%였음 → FiLM 한 번만으로도 충분히 강했음
- γ 분포가 0에서 날카로운 peak를 보였음 → 질문에 따라 feature map을 끄거나 선택적으로 키웠음
- t-SNE: 앞 층의 $$(\gamma, \beta)$$는 저수준 기능(color, shape)별로, 마지막 층은 고수준 기능(equal, compare)별로 묶였음 → 구조적 prior 없이도 기능 단위의 모듈성이 생겼음

### Related Work: 기반이 된 흐름
- **Conditional Normalization**: FiLM은 CN 계열의 일반화였음. image stylization(CIN, AdaIN), speech recognition(Dynamic Layer Norm), VQA(CBN)에서 쓰인 조건부 affine 변환을 정리했음
- **Neural Module Networks 및 프로그램 기반 추론**: 프로그램이나 모듈 구조를 명시적으로 구성하는 접근과 대비해, FiLM은 program supervision이나 특수 모듈 없이 학습하는 방법으로 제시되었음
- **Relation Networks**: 관계 비교를 명시적으로 처리하는 접근과 비교되었고, FiLM은 연산 비용이 영상 해상도에 따라 늘지 않는다는 장점이 있었음
- **기타 연결**: SE-Net, LSTM gate(입력 자신을 조건으로 하는 (0, 1) scaling), Hypernetwork(한 네트워크가 다른 네트워크의 파라미터를 생성), Mixture of Experts(조건에 따른 선택적 계산)

## 6. Discussion & Extensions

### 6.1 딥러닝 3축(데이터 / 모델 / 학습 방법)에서의 위치
- **모델 축**의 논문이었음. 그중에서도 조건 정보를 네트워크에 주입하는 방식(conditioning mechanism)을 다뤘음

| 축 | FiLM이 한 것 | 비고 |
|---|---|---|
| **모델** | 핵심. 질문을 CNN에 넣는 방식을 "융합(fusion)"에서 "feature-wise 변조(modulation)"로 바꿨음 | 기여 전부가 여기에 있었음 |
| 데이터 | 의도적으로 건드리지 않았음 (augmentation X, program label X) | "데이터 쪽 도움 없이도 된다"는 것이 주장의 일부였음 |
| 학습 방법 | 평범한 end-to-end 학습 (cross-entropy, Adam) | zero-shot은 학습법이 아니라 학습 뒤 $$(\gamma, \beta)$$ 공간에서 하는 조작이었음 |

- 데이터와 학습 방법을 평범하게 고정하고 구조 하나만 바꿔서 결과가 달라짐을 보인 실험 설계였음

### 6.2 궁극적으로 해결하려던 것
- **직접적인 질문: "추론하려면 추론 전용 구조가 꼭 필요한가?"**
    - 일반 모델(CNN+LSTM, Stacked Attention)은 CLEVR에서 실패했음 → 데이터 bias에 기대고 다단계 추론을 못 했음
    - 그래서 "추론 구조를 직접 넣어야 한다"는 흐름이 생겼음 (NMN, PG+EE, Relation Network)
    - FiLM의 반론: 일반 모델이 실패한 이유는 추론 구조가 없어서가 아니라 **질문이 이미지 처리에 개입하는 방식이 약해서**였음
        - 기존 방식은 이미지 처리가 끝난 뒤 질문과 한 번 섞었을 뿐이었음
        - 질문이 CNN 연산을 층마다 직접 바꾸게 하면 범용 부품만으로도 추론이 되었음
    - 핵심 논쟁은 inductive bias를 얼마나 넣어야 하느냐였음 (workshop 버전 제목도 *"Without Strong Priors"*였음)
- **일반적인 목표: conditioning을 범용 레이어로 정립하는 것**
    - CIN, AdaIN, CBN, DLN이 분야마다 "정규화 + 조건부 affine"으로 따로 쓰이고 있었음
    - 이를 normalization과 분리하고 하나의 범용 레이어로 통합해서 RNN, RL 등으로 확장할 수 있게 하려 했음

### 6.3 Attention과의 비교: feature-wise vs token-wise
- Attention도 이미 조건부 연산이었음 (Q = 질문, K/V = 이미지). 다만 **변조하는 축이 달랐음**

| | Attention (token-wise) | FiLM (feature-wise) |
|---|---|---|
| 변조 축 | token / 공간 축: 어디를 볼지 (where) | 채널 / feature 축: 어떤 feature를 쓸지 (what) |
| 연산 | 위치들의 가중 평균 | 채널별 scale + shift |
| 가중치 범위 | softmax: 0 이상, 합이 1 | 제한 없음: 음수, 0, 큰 값 모두 가능 |
| 할 수 있는 일 | 고르고 섞기 | 증폭, 억제, 끄기, 부호 반전 |
| 비용 | token 수의 제곱 | 채널 수에 비례, 해상도와 무관 |

- **연결 고리**  
    <img src="/assets/img/FiLM%20(4).png" alt="FiLM Fig. 4">
    - Fig. 4: 채널만 변조했는데도 질문 관련 위치에 활성이 몰렸음 → feature-wise 변조가 간접적으로 spatial attention 효과를 냈음 (Stacked Attention보다 성능이 좋은 이유로 제시되었음)
    - γ를 sigmoid (0, 1)로 묶으면 성능이 떨어졌음 → attention 가중치가 바로 이렇게 0 이상으로 제한된 형태였음. FiLM은 attention이 못 하는 부호 반전과 증폭을 할 수 있었음
- **Transformer에서 조건을 넣는 4가지 방식**
    1. **Cross-attention**: 조건을 K/V(또는 Q)로 넣었음 (Stable Diffusion text conditioning, Flamingo). token 단위로 세밀하게 주입했고, 조건이 구조를 가진 시퀀스일 때 적합했음
    2. **In-context / prefix token**: 조건을 token으로 만들어 시퀀스에 이어 붙이고 self-attention에 참여시켰음 → 조건이 attention 패턴 자체를 바꿨음
        - CLS/class token (DiT의 in-context conditioning 변형)
        - Prefix-tuning (Li & Liang, ACL 2021), Prompt tuning (Lester et al., EMNLP 2021): 학습되는 prefix로 task를 지정했음
        - VPT (Jia et al., ECCV 2022): ViT 입력에 학습되는 prompt token을 추가했음
    3. **AdaLN / adaLN-Zero (Transformer 버전 FiLM)**: LayerNorm의 $$\gamma, \beta$$를 조건에서 회귀했음
        - attention 입력이 변조되므로 Q, K, V가 모두 조건에 따라 달라졌음 → attention 패턴도 간접적으로 바뀌었음
        - DiT (ICCV 2023)에서 in-context, cross-attention, adaLN, adaLN-Zero를 비교했고 adaLN-Zero가 FID와 연산량 모두 가장 좋았음 (조건이 timestep, class 같은 전역 벡터일 때)
        - adaLN-Zero는 residual branch 앞의 gate $$\alpha$$를 0으로 초기화해서 block이 처음에 identity가 되게 했음 (CBN의 $$\Delta = 0$$과 같은 발상)
        - 최근 모델(SD3 등 MMDiT)은 둘을 같이 썼음: 전역 조건(timestep)은 adaLN, 구조적 조건(텍스트)은 attention
    4. **Attention 내부 직접 변조**
        - logit에 조건부 bias를 더했음: relative position bias, ALiBi (위치를 조건으로 하는 β)
        - 출력에 gate를 곱했음: gated attention (e.g., Qwen 팀 *Gated Attention for LLMs*, 2025) → 입력 자신을 조건으로 하는 γ-only FiLM과 비슷했음
        - task-conditioned Transformer: CA-MTL (ICLR 2021, task-conditioned attention + conditional LN), Hyperformer (ACL 2021, task embedding에서 adapter 파라미터 생성)

| 조건의 형태 | 맞는 방식 |
|---|---|
| 전역 벡터 하나 (timestep, class, task ID, style) | FiLM / AdaLN (싸고 효과적) |
| 구조가 있는 시퀀스 (문장, 여러 객체) | Cross-attention (token별 정렬 필요) |

- **"channel attention"이라는 이름의 함정**: SE-Net, CBAM의 channel attention은 이름만 attention이고 실제로는 입력 자신을 조건으로 하는 FiLM($$\gamma \in (0,1)$$, β 없음)이었음. FiLM 논문도 Related Work에서 SE-Net을 이렇게 분류했음
- **ViT Register는 조건부 변조가 아니었음** (Darcet et al., *Vision Transformers Need Registers*, ICLR 2024)
    - 대형 ViT(DINOv2, CLIP 등)에서 정보가 적은 patch 일부에 high-norm artifact token이 생겼음 → 모델이 이 patch를 전역 정보 저장 공간으로 재활용하고 있었음
    - 해결: 학습되는 여분 token(register)을 추가하고 출력에서 버렸음 → 전역 계산은 register에서 하고 patch token은 깨끗해졌음
    - 구조는 prompt token과 거의 같았지만, 조건과 무관한 "메모장(scratch space)" token이라는 점이 달랐음
    - register를 조건에서 생성하게 바꾸면 prefix conditioning이 되었음
    - LLM의 attention sink 현상과 같은 계열로 해석되었음

| | Register | Prompt token (VPT, prefix) | FiLM / AdaLN |
|---|---|---|---|
| 입력에 따라 달라지나 | ❌ 모든 입력에 같은 벡터 | ❌ task마다 고정 | ✅ 조건에서 계산 |
| 목적 | 연산 공간 제공, artifact 제거 | task 지정, 효율적 적응 | 조건에 따른 동작 변경 |
| 넣는 위치 | token 축 | token 축 | 채널 축 (LayerNorm) |
