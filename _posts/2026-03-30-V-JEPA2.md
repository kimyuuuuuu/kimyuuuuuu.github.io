## 1. Contribution & Motivation  
### Problem Statement   
- 기존의 세계 모델: 'state-action' sequence가 포함된 상호작용 데이터에 의존.  
  → 가용성 ↓, 확장성 ↓  
- 비디오 생성 기반 모델: 계산 비용 高, 픽셀 단위의 불필요한 세부 사항에 집중.   
 
### Key contribution   
- 100만 시간 이상의 인터넷 비디오로 사전 학습된 거대 비디오 인코더(V-JEPA 2)를 제안.  
- 매우 적은 양의 로봇 상호작용 데이터(62시간)만으로 행동 조건부 세계 모델(V-JEPA 2-AC)을 구축.  
- 이를 통해 새로운 환경에서 추가 학습이나 보상 함수 없이도 Zero-shot 로봇 조작(Pick-and-Place 등) 및 계획이 가능함을 입증.  

### Critical View  
- 구조적 혁신(JEPA의 latent space prediction) + 대규모 데이터 스케일링 = 성능 향상   
- 언어 감독 없이 학습된 비디오 인코더가 텍스트 정렬 후 SOTA  

## 2. Architecture & Pipeline   
![JEPA2 overview](/assets/img/V-JEPA2_overview.png)  
- 1단계: Mask denoising을 통한 비디오 사전학습  
- 2단계: 고정된 인코더(V-JEPA2, frozen)을 이용해 세가지 방식으로 확장.  
    - Language Alignment: V-JEPA2의 시각적 표현을 LLM과 연결 → Video QA 가능 (고수준 이해 능력)    
    - Attentive Probe Training: 인코더 위에 probe 추가, 특정 작업 수행능력 학습 → Action Classification, Object Recognition, Action Anticipation.  
    - Action-Conditioned Post-Training: V-JEPA2 + robot data (states, + actions) → 로봇 제어 가능.  

- Post training
    - 원하는 작업에 더 맞게 추가 학습.  
    - supervised fine tuning: '질문-답변'쌍 추가 학습.  
    - Reinforcement Learning from human feedback: 모델의 대답 중 1개 선택, 그 방향으로 강화.  
    - Alignment : 모델의 가치관을 인류 윤리 등에 맞춤.  

![Multistage training](/assets/img/V-JEPA2_Multistage.png)  
- V-JEPA2: 비디오 사전 학습 
    - Mask-Denoising objective: 원본 비디오 프레임 중 일부를 Masking, 모델이 가려진 부분의 representation을 예측하도록 학습.  
    - Joint-Embedding Predictive Architecture (JEPA): 픽셀을 직접 생성하는 대신, 추상적인 특징(embedding) 공간에서 예측을 수행.  
    - EMA Encoder: 학습 중인 Encoder의 가중치를 지수 이동 평균(EMA)하여 Target으로 사용함으로써, 학습의 안정성을 높이고 표현 붕괴(representation collapse)를 방지.  

- V-JEPA 2-AC: 액션 조건부 사후 학습  
    - Action-Conditioned (AC): 특정 Robot actions & poses(로봇의 관절 각도, 집게 상태 등)가 주어졌을 때 미래 상태가 어떻게 변할지를 예측.  
    - Frozen Encoder: pre-trained video encoder frozen, 그 위에 새로운 Predictor만 학습.  
    - Autoregressive Prediction: 과거 프레임들과 행동 데이터를 바탕으로 미래 프레임의 특징값(t_4t4t_4t4​)을 예측하며, 이를 통해 로봇이 목표 이미지에 도달하기 위한 최적의 행동 순서를 계획(Planning).  

- Module
    - ViT & 3D-RoPE(시간, 높이, 너비 측에 대해 별도의 회전 위치 임베딩 적용)

## 3. Methodology & Theory   
- Loss Function
    - Pre-training: $\L_1$ 거리 기반의 마스크 토큰 예측 손실 사용.  
      $\min_{\theta, \phi, \Delta_y} \| P_{\phi}(\Delta_y, E_{\theta}(x)) - \text{sg}(\bar{E}_{\theta}(y)) \|_1 $  

  - AC Post-training: Teacher-forcing과 2단계 롤아웃(Rollout) 손실의 합을 최소화.   
      $\mathcal{L}(\phi) := \mathcal{L}_{\text{teacher-forcing}}(\phi) + \mathcal{L}_{\text{rollout}}(\phi) $  

- Algorithm: **Model Predictive Control (MPC)**를 사용하여 계획 수행.   
    -  목표 이미지(\(z_g\))와 예측된 미래 상태 사이의 \(L_1\) 거리를 최소화하는 액션 시퀀스를 **Cross-Entropy Method (CEM)**로 최적화.  

## 4. 실험 및 데이터 (Experiments & Results)  
- Datasets
    - 사전 학습: VideoMix22M (SSv2, Kinetics, HowTo100M, YT-Temporal-1B, ImageNet 결합)     
    - 로봇 학습: Droid 데이터셋 (62시간 분량)   
- Performance: 동작 이해  
    - SSv2에서 77.3% Top-1 정확도  
    - 동작 예측: Epic-Kitchens-100에서 39.7 Recall@5 (기존 SOTA 대비 44% 향상)  
    - 로봇 계획: 새로운 환경에서 Pick-and-Place 성공률 65~80% 달성 (Zero-shot)  
- Ablation Study: 데이터 큐레이션(+1.4p), 모델 스케일링(+1.5p), 점진적 해상도 학습(8.4배 효율성 향상) 등이 성능 및 효율성에 기여함을 증명.
